# Sales Performance Dashboard
## Overview
An interactive Excel dashboard designed to monitor sales executive performance, compare sales results, and evaluate target achievement using Excel charts and VBA automation.
## Dashboard Preview
![Sales Performance Dashboard](images/Dashboard-Preview.png)
## Key Features
- City-based filtering for sales analysis
- Four dashboard views controlled by checkboxes
- VBA macros assigned to checkbox controls
- Sales executive performance rankings
- Total sales comparison
- Target achievement and performance gap analysis
- Interactive charts and visual summaries
## Tools & Technologies
- Microsoft Excel
- VBA (Visual Basic for Applications)
- Excel formulas
- Charts and data visualization
- Dashboard automation
## Workbook Structure
- `DASHBOARD` — Interactive dashboard with filters, charts, and checkbox controls.
- `RAW DATA` — Sales records, daily sales, total sales, targets, and performance percentages.
## How to Use
1. Download the Excel workbook.
2. Open it in desktop Microsoft Excel.
3. Enable macros only if you trust the workbook and its source.
4. Navigate to the DASHBOARD sheet.
5. Select a city to filter the sales information.
6. Use the checkbox controls to switch dashboard views.
7. Analyze sales rankings and target achievement.
## Project Objective
To simplify sales performance monitoring through interactive visualizations and VBA-based dashboard controls, helping users explore results and identify performance gaps.
